# AGENT DIRECTIVE: 80/20 MINIMALIST PRODUCTION ARCHITECTURE

## Core Philosophy: The 20/80 Rule
- **20% of the code produces 80% of the business results.**
- **Code Only.** No AI-generated scrap, no bloated abstractions, and no synthetic placeholders.
- **Zero Bloat:** Every single line of code must directly support visitor conversion, payment processing, or digital asset delivery.
- **Component Discipline:** Keep components concise, elegant, and focused (~50 lines of high-leverage code per critical component).
- **One Primary Action:** One primary button, one seamless path from value revelation to checkout and download.

## Technology Stack:
- **Framework:** Next.js 14 (App Router, Node.js Runtime, TypeScript)
- **Styling:** Tailwind CSS (Dark-mode cyber-clinical aesthetic)
- **Icons:** Lucide React
- **Payment Engine:** Razorpay (UPI, Cards, NetBanking)
- **Token Security:** Native Node.js `crypto` HMAC-SHA256 & `jose` signed JWT tokens
- **Asset Storage:** Protected local storage with cryptographic streaming gateway
- **Brand Standard:** **Brain OS** (`brainos.site`)
