# Protected Digital Storage

This directory contains the master deliverable file(s) for Brain OS (e.g., `BrainOS-Master-Vault.zip`).

### Security Notice:
- **Strictly Ignored**: All archive files (`*.zip`, `*.tar.gz`, `*.rar`, etc.) in this folder are ignored by Git via `.gitignore`.
- **Proprietary Asset Protection**: Never commit commercial digital products or sensitive archives to version control.
- **Production Setup**: Place your verified release archive (`BrainOS-Master-Vault.zip`) directly into this directory on your hosting server or configure an external secure storage provider (e.g., AWS S3, Cloudflare R2) via `STORAGE_LOCAL_PATH`.
