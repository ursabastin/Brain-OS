# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or accidental exposure within this repository, please DO NOT open a public GitHub issue.

Please report vulnerabilities privately by emailing:
**support@brainos.site**

Include the following information:
- Description of the vulnerability or data issue
- Steps to reproduce
- Potential impact
- Suggested fix (if known)

We will review your submission and respond within 24 to 48 hours.

## Commercial & Intellectual Property Protection

This repository is configured to exclude all commercial digital deliverables (e.g. `BrainOS-Master-Vault.zip` and any other zip archives) and local environment secrets (`.env.local`). If you fork or clone this repository, maintain `.gitignore` rules to prevent proprietary asset leakage.
